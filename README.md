# Neura — AI SaaS Landing Page Template

A premium, responsive, multi-page AI SaaS marketing website by **Universe404 Dev**. Built with semantic HTML5, custom CSS, and vanilla JavaScript — no framework, build step, or paid dependency required.

## Pages
- `index.html` — homepage and product overview
- `features.html` — feature sections
- `pricing.html` — responsive pricing cards with monthly/yearly toggle
- `about.html` — brand story and values
- `contact.html` — validated contact form with optional endpoint
- `faq.html` — accessible native disclosure FAQ

## Quick start
1. Download or clone this repository.
2. Open `index.html` in a browser, or serve the folder with any static web server.
3. Edit brand, form endpoints, checkout links, and social links in `assets/js/config.js`.
4. Replace the sample product copy, prices, and claims with your real business information.
5. Deploy the folder to any static host.

## Important
This is a **front-end website template**, not a working SaaS application. It does not include AI inference, authentication, billing, a database, or a backend. The contact form remains in demo mode until you configure an HTTPS endpoint. Checkout URLs are placeholders and must be supplied by your payment provider.

## Customization
- Colors, typography, spacing, responsive layouts: `assets/css/styles.css` (`:root` variables near the top).
- Shared navigation, footer, menu, reveal animation, pricing toggle, and form behavior: `assets/js/main.js`.
- Brand and integration settings: `assets/js/config.js`.
