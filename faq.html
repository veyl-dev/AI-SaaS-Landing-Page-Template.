Does this template include an AI backend?

No. This is a static HTML, CSS, and vanilla JavaScript website template. It does not include AI models, authentication, a database, or server-side processing.

Can I customize the colors and content?

Absolutely. Update the CSS variables in assets/css/styles.css, edit the page content, and change brand links and endpoints in assets/js/config.js.

Do the contact forms work out of the box?

The forms include front-end validation and a clear demo state. Add your own HTTPS form endpoint in the configuration to receive submissions.
